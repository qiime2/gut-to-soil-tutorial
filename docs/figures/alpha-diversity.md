**Three identity-based alpha diversity metrics.** Three alpha diversity metrics, *Observed Features* (panels **a** and **b**), *Shannon Diversity* (panels **c** and **d**), and *Pielou's Evenness* (panels **e** and **f**) are applied to the feature table in [](#fig-even-sampling)c. Each results in a `SampleData[AlphaDiversity]` artifact, which summarizes each sample in a single value. Logarithms in these formulas are base 2, matching QIIME 2.
