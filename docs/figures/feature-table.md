**A feature table and the corresponding feature sequences.** A `FeatureTable[Frequency]` (panel **a**) describes how many times each feature was observed in each sample. In this feature table, the features are amplicon sequence variants, and each ASV's sequence is stored in the corresponding `FeatureData[Sequence]` artifact (panel **b**). The rows in this feature table represent the samples and the columns represent the features.
