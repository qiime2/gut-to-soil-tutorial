**Simplified view of sample metadata for a few samples in the constructed data.** Sample metadata for the constructed data set used in the manuscript figures. Throughout the figures in this manuscript, we'll follow a constructed, illustrative set of samples through data analysis. These are the metadata that describe these samples. In general, metadata is provided in `.tsv` files. Notice that there are three color-coded sample types: Human Excrement (orange), Human Excrement Compost (blue, with lightness correlated with the Composting Time Point), and Food Compost (green). The first six samples are associated with a single biological replicate called Bucket 42, and the final sample is not associated with a biological replicate. Because the "Bucket" column does not have an applicable value for sample `d419`, that cell is left blank per the `rachis` metadata standard for representing missing or inapplicable metadata.
