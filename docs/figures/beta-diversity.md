**Two identity-based beta diversity metrics.** Two beta diversity metrics, *Jaccard distance* (panels **a** and **b**) and *Bray-Curtis distance* (panels **c** and **d**), are applied to the feature table in [](#fig-even-sampling)c. Each results in a `DistanceMatrix` object, where the values are interpreted as the dissimilarity between the pair of samples it represents (larger values indicate less similar samples).
